# kevinkeithley.github.io

Source for [kevinkeithley.github.io](https://kevinkeithley.github.io), my
professional website and résumé.

## History

This site began as an individual project for a web-development class. The
original version was a small, business-card-style page built with plain HTML and
CSS. I have continued building it since the class ended, gradually turning it
into a living professional site rather than leaving it as a completed school
assignment.

The current version brings together work that has crossed several disciplines:
economic modeling, data science, software development, restaurant operations,
small-business ownership, and structural integration. It also documents current
projects including KitchenPi and
[Self-Taught Scholar](https://www.selftaughtscholar.com/).

## Current site

The site includes:

- a concise professional homepage;
- an expanded About page connecting the different parts of my work;
- selected current projects;
- links to GitHub and LinkedIn;
- a downloadable, ATS-readable résumé; and
- responsive layouts for desktop and mobile screens.

## Technical approach

The site intentionally remains lightweight:

- semantic HTML;
- hand-written CSS;
- no JavaScript dependency;
- no build step; and
- deployment through GitHub Pages.

This keeps the site fast, easy to inspect, and easy to maintain.

## Design system

[`DESIGN_SYSTEM.md`](DESIGN_SYSTEM.md) records the shared visual and editorial
system used by the website and résumé, including colors, typography, spacing,
components, responsive behavior, accessibility rules, and writing voice.
